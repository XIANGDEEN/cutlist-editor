# 剪辑单字段契约

> 给用户的模板就是这张表。**列名固定**，顺序可换，空单元格 = 用默认值。

## 表 A · 全局

| 字段 | 允许值 / 写法 | 默认 |
| --- | --- | --- |
| 片名 | 任意文本（做文件名，别带 `\/:*?"<>|`） | 首个素材名 |
| 画幅 | `竖屏`(1080×1920) / `横屏`(1920×1080) / `方形`(1080×1080) / `1080x1920` 自定义 | 竖屏 |
| 帧率 | 整数，常用 24 / 30 / 60 | 30 |
| 目标时长 | 秒数，或 `不限` | 不限 |
| 素材文件夹 | 一个目录路径 | — |
| BGM 文件 | 音频路径，或 `无` | 无 |
| BGM 音量 | 0–1 | 0.6 |
| 原声处理 | `保留` / `静音` / `压低` | 保留 |
| 片头 / 片尾 | `无`，或 `有,0.8`（秒） | 无 |
| 字幕字体 | 系统字体名（Windows 常见：微软雅黑 / 思源黑体 / 黑体） | 微软雅黑 |
| 音效目录 | 存放 `<音效名>.wav` 的目录（缺哪个自动合成哪个） | `assets/sfx` |
| 音效音量 | 0–2 | 0.8 |
| 输出目录 | 路径 | `out/` |

## 表 B · 素材清单（可选）

| 列 | 说明 |
| --- | --- |
| 简称 | 表 C 里引用它，如 `s1` |
| 文件路径 | 绝对路径或相对素材文件夹 |

## 表 C · 镜头表

| # | 列名 | 必填 | 允许值 / 写法 | 默认 | 语义 |
| --- | --- | --- | --- | --- | --- |
| 1 | 序号 | 是 | 整数 | — | 只用于对号，不影响顺序 |
| 2 | 素材 | 是 | 简称或路径 | — | 画面上出现的那条素材 |
| 3 | 入点 | 是 | `mm:ss.s` / `hh:mm:ss.mmm` / 纯秒 | — | 从素材哪里开始 |
| 4 | 出点 | 是 | 同上，必须 > 入点 | — | 到哪里结束（**不含**该帧） |
| 5 | 时长 | 否 | 留空 | 自动算 | 写了我也按入出点算，仅作校验 |
| 6 | 速度 | 否 | 0.25–4.0 | 1.0 | 1.25 = 加速，0.5 = 慢放；音轨同步 atempo |
| 7 | 画面 | 否 | `原样` / `推近` / `拉远` / `抖动` / `局部放大:左\|中\|右` | 原样 | v1 实际支持：原样 / 推近 / 拉远 / 局部放大（静态裁切）；抖动降级为原样 |
| 8 | 转场 | 否 | `硬切` / `叠化,D` / `闪白,D`（D = 秒，0.1–1.0） | 硬切 | 指**到下一镜**的过渡；D 会吃掉总时长 |
| 9 | 字幕 | 否 | 文本；换行写 `\n` | 无 | 该镜全程显示 |
| 10 | 字幕样式 | 否 | `预设` / `强调` / `小字` / `无` | 预设 | 强调=更大更粗，小字=角标 |
| 11 | 声音 | 否 | `原声` / `静音` / `压低` | 跟表 A | 该镜声音处理 |
| 12 | 音效 | 否 | `呼呼`/`重击`/`咔`/`弹出`/`上升`（或 `whoosh`/`boom`/`click`/`pop`/`riser`），可带音量 `重击:0.7`；`无` = 不配 | 无 | 叠在该镜声音下；文件缺失会现场合成 |
| 13 | 备注 | 否 | 任意文本 | — | 给人看的；要执行须翻译成参数并回读 |

## 示例

```csv
序号,素材,入点,出点,时长,速度,画面,转场,字幕,字幕样式,声音,音效,备注
1,s1,12:30.5,12:33.0,,1.25,推近,硬切,开局第一波,预设,原声,,从进房开始剪
2,s1,13:05.0,13:09.4,,0.5,局部放大:中,闪白 0.15,三杀,强调,原声,重击:0.7,慢放，保留播报音
3,s2,0:08.0,0:11.5,,1.0,原样,叠化 0.3,残局翻盘,预设,压低,呼呼,结尾，BGM 收一下
```

## 校验规则（`check_cutlist.py` 会逐条查）

| 规则 | 严重度 |
| --- | --- |
| 必填列缺失 / 行缺值 | 错误 |
| 时间码无法解析 | 错误 |
| 出点 ≤ 入点 | 错误 |
| 素材文件不存在 | 错误 |
| 出点 > 源时长 | 错误（建议改单，不硬剪） |
| 速度不在 0.25–4.0 | 错误 |
| 转场值未知 | 警告（降级成硬切并写进报告） |
| 画面值未知 | 警告（降级成原样） |
| 音效值未知 | 警告（该镜不配音效） |
| 最后一镜写了转场 | 警告（没有下一镜可切，忽略） |
| 总时长偏离目标 > 20% | 警告 |
| 单镜短于 0.3 秒 | 警告（可能是误填） |

## 解析约定

- 编码 UTF-8（带 BOM 也能读），逗号分隔；文本里含逗号请用引号
- 空行跳过；以 `#` 开头的行视为注释
- 列名大小写不敏感，前后空格忽略
- 同一素材可重复引用，不同入出点 = 不同镜头
- **时间码按冒号右对齐解释**：`12:30.5` = 12 分 30.5 秒（不是 12 小时 30.5 秒），`01:02:03.400` = 1 时 2 分 3.4 秒
- 转场列写的是「本镜切到下一镜」的方式，因此**最后一镜的转场不会生效**（会给出警告）
