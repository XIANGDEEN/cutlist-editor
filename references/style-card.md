# 风格卡：从样片抽风格，再落到剪辑单上

用户给一段"我想要这种感觉"的样片。**不要凭感觉形容，要量化到能写进剪辑单的参数。**

## 抽取八维

| 维度 | 怎么量 | 落到哪个字段 |
| --- | --- | --- |
| 节奏 | 数 60 秒内切换次数 → 平均镜头长度；记最短/最长 | 镜头时长、出点分布 |
| 切换方式 | 逐次看接点：硬切/叠化/闪白/划像，算占比 | `转场` 列默认值 |
| 变速 | 有没有慢放/快放，用在哪类镜头 | `速度` 列 |
| 构图 | 主体在画面什么位置、有无留白/黑边、是否满屏 | `画幅`、`画面` 列 |
| 调色 | 亮/暗、高对比、饱和偏高还是偏低、暖冷 | 预览阶段说明（v1 不自动调色，靠 render 的 eq 参数） |
| 字幕 | 位置（顶部/底部/居中）、字号相对画面高度、描边、出现方式 | `字幕`+`字幕样式` |
| 声音 | 原声占比、BGM 有无、转场音效、原声是否被压低 | `声音` 列、BGM 音量 |
| 结构 | 开头几秒是不是钩子、中段怎么铺、结尾怎么收 | 镜头顺序建议 |

## 怎么做（不用专业工具）

1. `python scripts/probe.py 样片.mp4` 拿时长/分辨率/帧率；
2. 每 2 秒抽一帧存成图，肉眼扫一遍节奏：`ffmpeg -i 样片.mp4 -vf fps=0.5 frames/%03d.jpg`
3. 抽 3 段各 10 秒连看，只记**接点**：硬切占多少、有没有叠化；
4. 字幕：量一下字幕高度占画面高度比例（常见 4%–7%），记位置；
5. 声音：听有没有转场"嗖"声、原声是否闷（被压低）。

## 输出模板（填好给用户确认）

```markdown
## 风格卡：<样片名>

- 平均镜头长度：2.4 秒（最短 0.8 / 最长 6.0）→ 快节奏
- 切换：硬切 80% / 叠化 15% / 闪白 5%
- 变速：高潮段 0.5 倍慢放，其余 1.0
- 构图：满屏无黑边，主体居中偏上
- 调色：高对比、饱和 +15%、微冷
- 字幕：底部居中，字高约画面 6%，白字黑边粗描边
- 声音：原声为主，BGM 低于原声（约 0.4），转场有短促音效
- 结构：开场 1 秒直接进画面，无片头；结尾 0.5 秒定格

## 映射到剪辑单
- 全局：画幅=竖屏，帧率=30，BGM 音量=0.4，原声=保留
- 镜头默认：转场=硬切，字幕样式=强调，画面=原样
- 特殊：高潮镜头速度=0.5，画面=推近
```

## 三条纪律

1. **先给风格卡，再改剪辑单**：用户确认风格卡后，才把默认值写进剪辑单，避免改五十行。
2. **样片能给的只有"参数区间"**：具体哪段素材用慢放，仍然由用户决定。
3. **抽不准就说抽不准**：样片太短（<10 秒）或切换太少时，直接说"样本不足，只能给 2 个维度"。
